## 关键设计决策备忘

1. **记忆相关度阈值 ≥0.5**：低于阈值的记忆不参与回复，避免无关信息污染
2. **语义冲突优先更新旧记忆**：避免记忆条目无限膨胀
3. **Embedding 统一走 router**：移除直连 provider 的 `embedding_model` 配置，所有 embedding 请求经 router 分发，便于后续切换 provider
4. **笔记拓扑预提取**：实体在保存时提取，查看时零 LLM 调用，降低延迟和成本
5. **DownloadRegistry FIFO**：单 URL 覆盖删除曾导致进度事件丢失，改为并发锁 + FIFO 注册表保证事件配对
6. **频道 MessageTimeline 删除**：MessageCard 已包含时间线渲染逻辑，冗余组件移除减少维护成本
