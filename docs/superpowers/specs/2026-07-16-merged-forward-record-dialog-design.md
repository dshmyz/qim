# 合并转发聊天记录弹层设计

## 目标

将合并转发消息从卡片内完整展开改为微信式两层展示：消息气泡只提供可扫读的预览，完整记录在独立只读弹层中查看。

## 卡片层

- 显示“聊天记录”、总条数和最多三条“昵称：格式化摘要”。
- 通过整张卡片及“查看聊天记录”按钮打开完整记录。
- 不在气泡中内联渲染全部内容，避免撑开消息流。

## 记录弹层

- 新建 `MergedForwardRecordDialog.vue`，接收既有 `MergedForwardPayload`，不修改转发 JSON 或数据库。
- 标题显示“聊天记录（共 N 条）”；内容按时间顺序只读展示。
- 文本和 Markdown 显示正文；图片使用缩略图；文件、分享、小程序和资讯使用已格式化的摘要卡片。
- 每条记录显示发送者；相邻消息超过五分钟显示时间分隔。
- 点击遮罩、关闭按钮和 Escape 均可关闭；弹层开启时不影响原聊天消息状态。

## 边界与验证

- 不提供原消息跳转、回复、撤回或编辑；内容是转发时快照。
- 解析异常显示安全降级内容，不展示原始 JSON。
- 覆盖三条预览限制、弹层开启/关闭、文件摘要、时间分隔与无效快照的组件测试。
