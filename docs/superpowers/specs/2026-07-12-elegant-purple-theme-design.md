# “高雅紫”主题配色优化设计

## 目标

将 QIM 客户端的“高雅紫”从高饱和、大量紫色文字的风格，调整为偏冷、低饱和、轻盈通透的“月光薰衣草”方向。主题应保留明确的紫色识别度，同时适合长时间办公使用。

## 设计原则

- 大面积界面使用接近中性的冷白与浅薰衣草底色，不使用高饱和紫色铺满内容区。
- 主要文字改用深灰紫，紫色主色仅用于操作、选中态、自己的消息气泡和重点信息。
- 边框、悬停、阴影统一带少量冷紫倾向，避免纯灰突兀或阴影过重。
- 保留侧边功能栏渐变作为主题记忆点，其余区域保持克制。

| 深紫 | `#665486` | 活动态、按钮悬停、侧边栏渐变终点 |

## 覆盖范围

1. 更新 `elegant-purple` 主题的全局 CSS 变量，包括背景、文字、边框、悬停、激活、阴影和侧边栏渐变。
2. 同步更新短链接管理中独立的主题变量。
3. 检查并更新消息气泡、引用消息、已读状态、用户资料弹窗、AI 标记中针对 `elegant-purple` 写死的色值。
4. 更新主菜单和设置页中的主题预览色，使选择器与实际主题一致。
5. 不改动其他主题，不调整布局、字体或交互行为。

## 状态设计

- 默认：冷白背景、深灰紫文字、弱紫边框。
- 悬停：使用 `#EFEBF6` 浅紫底色，不额外提高饱和度。
- 选中/激活：使用主色或深紫，保持明确的状态区分。
- 焦点：聚焦环使用带透明度的主色，保留键盘可达性。
- 阴影：使用低透明度的冷紫黑，仅区分层级，不制造浮夸的悬浮感。

## 验收标准

- 切换到“高雅紫”后，主界面、消息和弹窗使用同一套薰衣草色板，无旧的高饱和艳紫残留。
- 正文与主背景、次要文字与主背景的对比度达到 WCAG AA 的常规文本要求。
- 自己的消息气泡上的文字保持清晰，悬停、选中与焦点状态可辨认。
- 主题菜单与设置页的预览色能准确传达实际主题。
- 客户端类型检查、相关测试和生产构建通过。

## 验证方法

- 搜索 `elegant-purple` 的所有专用样式，核对是否仍存在旧色板色值。
- 用颜色对比度计算验证主要文字、次要文字和消息气泡文字。
- 运行客户端的类型检查/测试与生产构建。
- 在桌面尺寸下切换主题，对主界面、消息区、弹窗和短链接页面进行截图检查。
