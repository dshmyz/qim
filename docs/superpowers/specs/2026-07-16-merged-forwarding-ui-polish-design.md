# 合并转发界面精修设计

## 目标

提升多条消息合并转发的辨识度、操作反馈和窄屏可用性，同时保持现有聊天主题和消息发送行为不变。

## 设计

- 合并转发卡片采用自适应宽度：常规窗口限制在舒适阅读宽度，窄屏占满可用气泡宽度。
- 卡片头部使用聊天记录图标、消息数量与展开箭头；文本、图片、文件采用一致的图标化摘要。
- 展开内容保持发送者、摘要与时间层级，长文本最多两行，避免内容撑开消息流。
- 多选框改为独立圆形浮层，选中时使用主题主色与勾选图标，避免负边距挤压消息内容。
- 底部多选操作栏使用半透明背景、阴影和主次按钮：取消为次操作，合并转发为主操作，少于两条时明确禁用。
- 在 640px 以下将操作栏改为紧凑布局，卡片减少内边距但维持可点击区域。

## 边界与验证

- 只修改呈现与交互样式；不改消息 JSON、接口、选择或发送逻辑。
- 所有颜色来自既有 CSS 变量，并为键盘 focus 提供清晰轮廓。
- 为卡片和操作栏的关键 class、禁用态和窄屏规则补充组件/源码断言；运行相关单测与前端构建。
