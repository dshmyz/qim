# 消息提醒目标系统名称设计

## 目标

消息提醒成功后，向发送者明确提示提醒实际送达的系统名称，而不是笼统显示“外部系统”。系统名称由管理员手动维护，适用于企业微信、飞书、Slack 或内部通知系统。

## 方案

- 在管理后台“消息提醒 Webhook”配置中增加 `system_name` 文本字段，供管理员填写目标系统名称。
- 服务端 `WebhookConfig` 读取并保留该字段；提醒发送成功时，将 `system_name` 写入 `remind_result` WebSocket 回执。
- 客户端从成功回执中读取该字段，显示“提醒已送达{系统名称}”。
- 为兼容已经保存的 Webhook 配置或未填写名称的配置，服务端和客户端均允许空值；客户端回退显示“提醒已送达外部系统”。

## 边界与验证

- 不根据 Webhook URL 推断系统类型，不影响 Webhook 请求、签名或失败提示。
- 管理后台保存和加载时应保留 `system_name`。
- 服务端成功回执应包含已配置的系统名称。
- 客户端应验证：存在名称时展示具体名称，名称缺失时仍展示“外部系统”。
