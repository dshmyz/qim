# QIM v2.0.24 发布说明

> 状态：发布候选稿，服务端完整测试已通过；正式发版前仍需完成工作区清理和部署验证
>
> 评审范围：`v2.0.23..HEAD`（当前 HEAD：`771dc88b`）以及工作区全部未提交改动。
>
> 本次范围共 184 个提交；工作区还包含未提交源码、构建产物和一个未跟踪二进制文件。

## 一、版本摘要

本版本主要围绕以下方向演进：

- AI 助手、群聊助手、分身记忆和流式回复能力增强。
- 外部 Bot、Webhook、MCP、QIM CLI 形成较完整的 Agent 交互闭环。
- 群文件空间和文件权限体系落地，并补充安全、并发和资源清理修复。
- 管理后台增加 AI 工具、Bot 运维、文档、版本管理等能力。
- 客户端统一右键菜单、通知、屏幕共享、转发记录和视觉体验。
- 任务、日历、提醒和通知调度能力增强。

## 二、功能变更

### 2.1 AI 与智能助手

- 新增 AI 侧边栏、快捷操作、群聊助手工具和群级记忆。
- 支持群聊助手代管成员、关键词门控和 `@AI` 优先触发。
- 增强“帮我回复”草稿模式，复用分身流式生成能力。
- 增加 AI 工具注册表、文档处理和文档相关管理入口。
- 完善分身记忆治理：三态会话激活、置信度门控、任务检索、Notes/Tasks 知识开关和记忆写入路径。
- 流式回复增加“思考中”状态、生成来源徽标和 Markdown 收尾处理。
- AI provider 对 4xx 错误快速失败，避免无效重试。
- 客户端禁止对 AI 助手发起屏幕共享。

### 2.2 外部 Bot、MCP 与 CLI

- 打通外部 Agent 与 QIM 用户之间的消息闭环。
- 支持 Bot 流式回复、卡片消息、卡片动作幂等、卡片状态回写和卡片删除。
- 新增 Webhook outbox 重试、死信兜底、投递监控和后台重投能力。
- 支持纯 pull 模式，解决断线期间流式收尾和 pull-mode agent 消息黑洞问题。
- 新增 QIM CLI 登录、Token 自动续期、会话自动创建/查找、消息发送、流式 stdin、任务/事件创建、会话查询、JSON 输出和自动更新。
- CLI 支持跨平台构建、Makefile 和服务端托管预编译二进制。
- 新增 qim-mcp stdio adapter 和 MCP Streamable HTTP transport。
- 补充 CLI/MCP 使用指南和 `send_message` 卡片使用说明。

### 2.3 群文件空间与文件能力

- 新增共享文件中心、群文件空间路由和群文件面板。
- 支持群成员上传、下载、排序和消息中的文件引用。
- 引入可复用的文件空间 scope 与集中式文件权限校验。
- 隔离个人文件空间、群文件面板状态和历史文件 scope。
- 补齐历史文件字段迁移、零 ID personal scope 回填和共享存储清理。
- 修复文件上传并发、FolderTree 渲染、群文件挂载和文件 URL 转发问题。
- 移除存在越权风险且收益有限的分块上传秒传逻辑。

### 2.4 客户端与交互体验

- 统一 Calendar、Task、File 等应用的右键菜单为 `UniversalContextMenu`。
- 完善合并转发：多消息选择、原生消息渲染、记录弹窗、Markdown/引用/撤回消息处理和预览布局。
- 增强通知中心，改由主进程 IPC 展示系统通知并使用应用图标。
- 修复屏幕共享全屏权限、全屏回退和权限诊断问题。
- Linux 非聊天面板使用自托管 Noto Color Emoji 字体。
- UI 图标由 Emoji 迁移至 FontAwesome，修复 Linux 显示异常。
- 支持按组织架构选择建群和邀请成员。
- 增加无障碍、截图、Bot 资料、消息菜单和客户端通用问题修复。

### 2.5 任务、日历和提醒

- 新增待办提醒字段与定时触发通知。
- 合并事件提醒和待办提醒调度任务，统一使用 robfig/cron。
- 修复时区对齐、已完成任务过滤、重复触发和提醒投递目标系统展示。
- 支持日期格双击/右键创建事件和任务。
- 修复任务可见性、看板排序、截止日期清空、指派和日历编辑/删除 Token 问题。
- 修复日历提醒不触发，并增加应用内通知和点击跳转。

### 2.6 管理后台

- 增加 AI 工具、Bot 运维、文档、公共文档和版本管理能力。
- 增加 Bot 列表、Webhook 投递监控和失败重投入口。
- 优化 Dashboard 快捷入口、模块配置和版本管理页面。
- 修复后台统计按本地午夜计算的问题。

## 三、安全性与稳定性修复

- 补充权限校验，修复多处 IDOR、越权访问、敏感信息泄露和资源泄露风险。
- 修复 Bot 限额过低和限流逻辑可能进入“死亡螺旋”的问题。
- 修复 GORM `IsActive` 零值判断和审批状态守卫。
- WebSocket 节点间通信协议支持配置 HTTPS。
- 修复文件 scope 迁移失败未阻止启动的问题。
- 集中并串行化共享存储清理，避免并发清理冲突。
- 修复群文件引用未按消息授权的问题。
- 修复客户端与后端安全修复后的上传流程及错误提示。

- [`qim-server/handler/admin_tools.go`](../../qim-server/handler/admin_tools.go)：群管理员不能通过 `remove_member`、`mute`、`unmute` 操作群主。

### 4.4 用户禁用状态与 Webhook vet 修复

- [`qim-server/cmd/echo-webhook/main.go`](../../qim-server/cmd/echo-webhook/main.go)：移除 `fmt.Println` 字符串中的重复换行，解除 Go vet 阻断。

## 五、已知问题与发布阻断项

### 已修复：后台禁用用户状态字段错误

用户管理工具此前写入连接状态 `status`，登录逻辑读取账号状态 `account_status`，导致禁用操作可能不生效。现已改为写入 `account_status`，并加入回归测试。

### 已修复：完整 Go 测试被 vet 错误阻断

`echo-webhook` 中 `fmt.Println` 的冗余换行已移除，完整 `go test ./...` 已通过。

### 其他发布注意事项

- 工作区包含大量未提交前端构建产物，不能直接整体提交或打包。
- [`qim-server/echo-webhook`](../../qim-server/echo-webhook) 是未跟踪的二进制文件，发版前应确认是否为构建产物并排除误提交。
- OAuth/CAS 历史账号与本地账号均可能使用 bcrypt 数据时，当前实现无法仅凭密码哈希可靠区分历史外部账号；如需禁止历史外部账号本地登录，应先确定兼容策略，不能通过全局拦截明文密码实现。
- OAuth state 目前依赖进程内存，多实例部署或服务重启期间登录回调可能失败，应在生产部署方式下验证。
