# QIM v2.0.44 发布说明

> 版本范围：`v2.0.43..v2.0.44`（共 8 个提交）

本版本以 AI 能力升级为主线：群助手完成智能化改造、AI 治理体系 P0–P5 全量落地，并修复了影响知识检索的 embedding 路由问题。

## 🤖 群助手智能化

- **@AI 提问默认走带工具的 ReAct**：普通提问从纯流式改为默认带工具的流式 ReAct（不支持流式 tool-call 的 Provider 自动降级）；自动回复走带工具的多步推理 + 质量门，工具链路失败降级原有编译图
- **工具面扩容**：群助手新增知识库搜索、任务清单、日历事件、文件搜索四个查询工具，按提问者数据边界取数——群里可以直接问"帮我查未完成任务"了
- **接话时机带对话历史**：意图判断注入最近 6 条折叠历史，"展开说说第一项"这类延续话题的追问不再被误判为闲聊而拒绝回复
- **质量门识别工具结果**：回复引用工具数据时审核必须看到工具输出，真实数据不再被误判为幻觉拒绝发送

## 🧠 AI 治理体系（P0–P5）

从可观测到自我进化的完整闭环：

- **P0 决策可观测**：每次 AI 回复/不回复都落决策留痕（触发门、让位、质量拒绝、队列忙等原因），分身设置新增「运行记录」Tab 可查
- **P1 回复质量**：意图检测改强/弱两层，陈述句不再被误触发；流式中断自动续写一次，仍不完整标注「（回复被截断）」；bot 补齐 system prompt
- **P2 治理看板**：管理后台新增「AI 治理」页，聚合回复完成率、每日趋势、反馈分布、学习信号
- **P3 健康门控**：模型调用级健康滚动评估，degraded 模型有替代时被路由自动跳过；默认关闭仅出建议，开启后窄域自动降权/恢复，动作全审计可一键回滚
- **P4 补丁进化**：质量门拒绝的失败案例聚类生成规则补丁，经黄金回放（通过率 ≥60%）+ 人工批准后注入对应场景的 system prompt，可随时停用
- **P5 夜间自动评估**：每日 03:17 定时执行健康评估与补丁提案生成，提案不自动生效，等管理员回放批准

## 🔧 AI 稳定性修复

- **知识检索 404 根因修复**：embedding 兜底不再丢弃任务绑定的模型名，语义检索（知识/记忆）恢复正常——此前会错误地用 chat 模型名调用 embeddings 接口导致全挂
- **@AI 误判清理**：`xxx@AI-support.com` 邮箱、英文单词内嵌 @AI 不再被误判为显式召唤；中文贴写（问下@小助）不受影响
- **路由兜底修正**：兜底 Provider 改用自身配置的模型，不再带着原路由模型名请求导致 400/404
- **角色伪造防护**：群历史拼装一条消息恒一行，用户粘贴的 `[assistant]: …` 行不再被误判为 AI 发言
- **直发文件不接话**：群里发文件不再触发 AI 逐个接话（直发图片保留）
- **判断类调用低温**：意图识别、质量审核等判断类调用固定 0.1 温度，消除判定抖动
- **看板每日趋势修复**：SQLite 下按本地日期分桶，真实数据不再恒为零

## 🧹 其他

- 测试修复：admin 路由数断言更新、移除已废弃回退逻辑的过时用例、性能基准迭代数适配超时、补齐 ChatWindow 测试的 API mock
