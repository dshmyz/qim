# QIM v2.0.39 发布说明

> 版本范围：`v2.0.38..v2.0.39`（共 2 个提交）

小版本，重点修复一个影响日常使用的下载问题。

## 📥 文件下载修复

- **修复：聊天里别人发的文件下载失败 / 报"下载中断"**
  此前文件下载仅"发送者本人"可用，导致单聊、群聊中他人发送的文件下载失败。
  现在后端把文件下载放宽为**登录即可下载**：

  - 发送者本人、单聊对端、群成员均可正常下载
  - 已删除的文件仍然无法下载
  - **服务端部署即可生效，客户端无需升级**——部署后即可直接下载聊天里他人发送的文件，旧版本客户端同样生效

## 🧹 其他

- 工程清理：移除误提交的测试二进制，避免仓库内生成文件干扰开发
