# NUIM 详细使用手册

> 面向 **终端使用者** 的一站式操作指引，涵盖即时通讯、办公应用、AI 助手/群助手、分身、文件空间与通知提醒。
> 开发/集成方请见 [CLI 使用指南](/docs/cli) 与 [MCP 接入指南](/docs/mcp)。

---

## 一、登录与会话

### 登录

1. 启动应用，输入用户名、密码。
2. 可选：勾选「记住密码」（本地**加密存储**），下次自动登录。
3. 后端不在本机时，可在登录界面「设置服务器地址」修改（默认 `http://localhost:8080`）。

### 会话类型

| 类型 | 说明 | 入口 |
|------|------|------|
| **单聊 / 私聊** | 一对一加密沟通 | 左侧「组织架构」→ 双击或「发起私聊」 |
| **群聊** | 多人协作，群公告、群文件、管理员 | 左侧「+」→「创建群聊」 |
| **讨论组** | 扁平化讨论，成员平等参与 | 「+」→「创建讨论组」 |
| **频道** | 订阅制信息发布，富文本 Markdown、审批机制 | 「+」→「频道」 |

### 会话管理

- **置顶**：固定重要会话到列表顶部。
- **免打扰 / 隐藏**：减少干扰或隐藏会话。
- **消息搜索 / 漫游**：按关键词、日期、类型筛选，多端同步。

## 二、消息通信

### 消息类型

| 类型 | 说明 |
|------|------|
| 📝 文本 | URL 自动识别转链接 |
| 🖼️ 图片 | 大图预览 |
| 📎 文件 | 上传、下载、另存 |
| 🔗 分享 | 笔记、便签、文件分享到用户/群聊 |
| 📱 小程序卡片 | 内嵌应用卡片 |
| 📰 资讯卡片 | 富文本资讯 |
| 🤖 Bot 卡片 | 带按钮的交互卡片，支持状态回写 |

### 常用操作

- **引用 / 回复**：悬停消息 → 回复，上下文清晰。
- **撤回 / 编辑**：2 分钟内撤回，撤回后可重新编辑回填。
- **@ 提及**：`@` 指定成员或 `@全体成员`。
- **已读回执**：群聊显示已读人数，单聊显示已读状态。
- **语音 / 视频**：WebRTC 音视频通话、屏幕共享（禁止对 AI 助手发起屏幕共享）。

## 三、应用中心

左侧栏「应用」进入：

| 应用 | 说明 |
|------|------|
| 📊 统计报表 | 消息趋势、文件分布、任务完成率可视化 |
| 📅 日历 | 月视图，事件管理，支持提醒 |
| 📝 笔记 | Markdown 编辑器，实时预览，可分享 |
| 📌 便签 | 快捷笔记，多色分类 |
| 📁 文件管理 | 个人文件、群文件空间、上传下载、分级权限 |
| ✅ 任务管理 | 看板视图，待办/进行中/已完成 |
| 🤖 AI 助手 | 智能对话机器人 |
| 🔗 短链接 | URL 缩短与管理 |

**分享内容**：笔记/便签/文件 →「分享」→ 选择用户或群聊 → 发送。

## 四、AI 助手与群助手

### AI 助手

「应用」→「AI 助手」→ 选择机器人对话。支持多模型、智能摘要、智能搜索。

### 群聊 AI 助手

群聊中可启用 AI 助手代答，三种触发方式：

1. **`@AI` 触发**：`@AI` + 提问，群助手优先响应。
2. **关键词门控**：配置关键词，命中自动回复。
3. **代管成员**：群助手托管指定成员，被 @ 时代答。

**群级记忆与知识库**：

- **群知识库**：群显式上传的权威文档，回答"事实是什么"。
- **群记忆**：从对话自动提炼的共识/约定/偏好，回答"这个群默认怎么做事"。
- 两者独立存储、刻意隔离。

### 帮我回复

收到消息可用「帮我回复」生成草稿（复用分身流式生成能力），编辑后发送。

## 五、AI 分身 / Avatar

分身让你离线时代为回复，是核心 AI 能力。

- **人设**：分析历史对话自动学习你的表达风格与角色定位。
- **触发规则**：在合适时机代为回复。
- **知识范围**：`notes`（主人笔记）、`tasks`（任务）知识开关控制回答领域。
- **回复策略**：仿真人延迟，避免机械感。
- **记忆**：分身从对话中提炼风格与偏好，支持三态会话激活、置信度门控、手动接管。

---

## 六、文件空间与知识库

### 文件空间

- **个人文件空间**：你的上传/下载、排序、消息引用。
- **群文件空间**：群成员共享，集中式权限校验 + scope 隔离。

### 群知识库

群知识库面向群助手/分身检索（上传 → 解析分块 → 向量化），与普通群文件是两套体系。公共文档由管理后台「文档管理」多版本维护。

---

## 七、通知与提醒

- **待办提醒**：任务/事件定时触发通知；管理后台可调提醒门槛、重复冷却。
- **通知中心**：聚合通知，点频道消息可跳转。
- **调度**：任务、日历、提醒、通知可后台调度触发。
